Interactive guide to four core Python concepts: modules and packages, exception handling, file I/O and JSON, and virtual environments and pip

Concept

What is a module?

A module is just a .py file. It holds functions, classes, or variables you can reuse in other files. Instead of writing the same code twice, you import it.

Think of it like a toolbox — you pick up the toolbox and use the tools inside whenever you need them.
import math
print(math.sqrt(16))   # 4.0

from math import pi
print(pi)              # 3.14159...
Concept

What is a package?

A package is a folder of modules. It groups related modules together. The folder needs an __init__.py file (can be empty) to tell Python it's a package.

myapp/
  __init__.py
  utils.py
  database.py

# Importing from a package
from myapp import utils
from myapp.database import connect
Concept

What is exception handling?

When something goes wrong in your code (dividing by zero, file not found, bad input), Python raises an exception. If you don't catch it, your program crashes. Exception handling lets you deal with errors gracefully.

Like a safety net — if a tightrope walker slips, the net catches them instead of letting them fall.
Syntax

try / except / else / finally

try:
    result = 10 / 0         # risky code goes here
except ZeroDivisionError:
    print("Can't divide by zero!")
except ValueError as e:
    print(f"Bad value: {e}")
else:
    print("No error! Result:", result)  # runs only if no error
finally:
    print("This always runs")           # cleanup code
Tip

Raising your own exceptions

def set_age(age):
    if age < 0:
        raise ValueError("Age can't be negative")
    return age
Concept

Reading and writing files

Python can read and write files with the built-in open() function. Always use with — it automatically closes the file even if an error happens.

# Writing to a file
with open("notes.txt", "w") as f:
    f.write("Hello, file!")

# Reading from a file
with open("notes.txt", "r") as f:
    content = f.read()
    print(content)   # Hello, file!

Common modes: "r" read, "w" write (overwrites), "a" append, "rb" read binary.

JSON

Working with JSON

JSON is a common format for storing and sharing data. Python's json module converts between Python dicts and JSON text.

import json

data = {"name": "Alice", "age": 30}

# Dict → JSON string (serialize)
json_str = json.dumps(data)

# JSON string → Dict (deserialize)
parsed = json.loads(json_str)

# Save to file / load from file
with open("data.json", "w") as f:
    json.dump(data, f)

with open("data.json", "r") as f:
    loaded = json.load(f)
Concept

What is pip?

pip is Python's package installer. Use it to install third-party libraries that don't come with Python.

# In your terminal (not in Python)
pip install requests
pip install pandas numpy
pip uninstall requests
pip list                   # see installed packages
Concept

What is a virtual environment?

A virtual environment is an isolated Python workspace. Different projects can have different package versions without conflicting with each other.

Like separate apartments — each project has its own space with its own stuff, so they don't mess with each other.
# Create a virtual environment
python -m venv myenv

# Activate it
source myenv/bin/activate    # Mac/Linux
myenv\Scripts\activate       # Windows

# Now install packages — they stay inside myenv
pip install flask

# Save your dependencies
pip freeze > requirements.txt

# Someone else can replicate your setup
pip install -r requirements.txt

# Deactivate when done
deactivate
